Для логики проекта требуется следующиая информация:
1. Реализовать регистрацию (и авторизацию) пользователя (через jwt token, передавать ты мне его должен куками, как и я тебе возвращать).
При регистрации тебе передаются следующие поля:
name - имя пользователя
email - email пользователя
password - пароль пользователя
phone - номер телефона пользователя
(также выделить место в бд для хранения ссылки на аватарку пользователя, аватарка будет задаваться после регистрации, в личном кабинете).
Из jwt я должен видеть следующее:
name,
email,
phone,
avatar - ссылку на аватарку,
is_admin - проверка на то, является ли пользователь админом 
2. Реализовать logout пользователя.
3. Реализовать удаление аккаунта пользователя.
4. !ПО ВОЗМОЖНОСТИ! Реализовать изменение аккаунта пользователя

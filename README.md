# 🍰 Sweet Story — Веб-сайт домашней кондитерской

Современный, уютный и интуитивно понятный веб-сайт для домашней кондитерской Елены. Проект создан с фокусом на сочный визуальный контент в стиле Pinterest, высокую скорость работы и автоматизацию приема заказов.

---

## 🎨 Концепция и Дизайн
* **Визуальный стиль:** Мягкая, «воздушная» и «вкусная» цветовая палитра (пастельные, кремовые и ягодные оттенки).
* **Интерфейс:** Минималистичный UX без лишнего текста. На первом плане — крупные, аппетитные фотографии тортов и понятные целевые кнопки (CTA).
* **Адаптивность:** 100% Mobile-first подход. Сайт идеально оптимизирован под смартфоны, чтобы не упустить ни одного заказа.

---

## ✨ Ключевой функционал

### 1. Интерактивный калькулятор заказа
Клиент может самостоятельно собрать свой идеальный торт на сайте:
* Выбор параметров (вес, количество ярусов).
* Выбор бисквита, начинки и стиля декора.
* Динамический расчет стоимости в реальном времени.

### 2. Умный календарь бронирования (с лимитами)
* **Для клиента:** Наглядный календарь для выбора даты выдачи. Дни, на которые уже оформлено **3 заказа**, автоматически становятся недоступными для выбора (так как Елена печет одна).
* **Для кондитера (Dashboard):** Защищенная админ-панель. Отображает список заказов по дням, выбранные начинки, контакты клиентов и статусы («В работе», «Готов», «Выдан»).

---

## 🛠 Технологический стек

* **Фреймворк:** Next.js 14+ (App Router)
* **Стилизация:** Tailwind CSS (для быстрой и гибкой верстки)
* **Валидация и Формы:** React Hook Form + Zod

---

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/Goblins-and-me/Frontend.git
```

### 2. Установка зависимостей
```bash
npm install
# или yarn install / pnpm install
```

### 4. Запуск сервера разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере для просмотра результата.

## 📁 Структура директорий

```text
src/
├── app/                  # Роутинг (Next.js App Router)
│   ├── page.tsx          # Главная страница (Landing page в стиле Pinterest)
│   ├── calendar/         # Страница конфигуратора торта
│   ├── admin/            # Панель кондитера (управление заказами)
|   ├── order/            # Страница оформления заказа
|   └── product_card/     # Карточка товара (находиться на отдельной странице)
|
├── components/           # Компоненты интерфейса
│   ├── ui/               # Базовые элементы (кнопки, формы, инпуты)
│   ├── calculator/       # Компоненты логики подсчета стоимости
│   └── calendar/         # Интерактивный календарь с проверкой доступности
└── types/                # TypeScript интерфейсы (Заказ, Начинка, Клиент)
```
_(может меняться в течении разработки)_
